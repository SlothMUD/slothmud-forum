<div class="post" data-post-id="8553" data-author="kjartan" data-date="2005-09-06T15:35:56+00:00">

Resectoring isn't by itself going to produce any immediate game changes, but it will make lots of nice stuff possible.  Previously we were using the stock dikumud list of room types, plus a couple that had been added.  There were about 10.  We have made a more detailed list, which is up to about 70, and we are reclassifying all the rooms as one of the new types.  (Many of the old types are still in the list, actually.)

The immediate use is for caches: we can randomly generate mob lairs better if we know better what sort of room it is.  Some other things we might do:

- if a room is cemetery, tomb, or charnel house, give necros some sort of bonus there for creating undead

- if a room is stairway and you get tripped, have a chance of falling down the  stairs

- a quest/forge/etc could require that you find a certain type of room, e.g. a volcano

- etc.

We did something similar with mob species about a year ago and I have found a number of places where that was useful.  They're mostly minor effects; things like not letting you trip mobs that don't have legs.
