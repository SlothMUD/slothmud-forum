I was just thinking of a couple thief skills that would be nice, yet wouldn't really add much power. Mostly these are for convience when using poison. Obviously I'm not married to any names, so if you happen to implement them call them what you want. I have thought multiple times that both of these would be nice.

1\. Inspect Weapon: It would be nice to be able to look at a weapon and see if there is any poison on it (and what kind of poison). It would also be nice to be able to do this without removing it.

Ex: "Inspect Fangs": You see 2 applications of iocaine applied to the Fangs.

2\. "Wipe Weapon: If i apply iocaine, but then decide i would rather use ryodine, it would be nice to do this without having to stab something first to clear the iocaine. 

Ex: "Wipe Fangs": You carefully wipe the Fangs clean.

If i had my choice between the 2, i would much rather have #2. Just a thought, take it or leave it <img src="/images/smilies/icon_e_smile.svg" alt=":)" title=":)" width="15" height="15" class="smiley nozoom">
