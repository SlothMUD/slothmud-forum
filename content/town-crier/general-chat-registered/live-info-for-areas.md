Ok.  Using avatars, it's possible to rip up the mud. Without them, life gets a lot more interesting.

So, while I was sitting back wondering what to run, here's an idea that went flitting through my mind:

Would it be possible, using one of the many live update things we have on this wonderful game, to add a mobs list to the Cartography section?  We have comments and equipment, it would be very very cool to have a section for mobs.  And by this, I mean a generic listing of the mobs in the area, and how much base xp (no time alive xp) they each are.

I'm thinking this would serve a few purposes... 

1) It might help discourage the occasional newbie that thinks they can solo the flame.

2) It would give folks a much better idea of how hard the area is beyond the insanely vague descriptions we have now.

3) It would help give leaders an idea of where to run their groups.

I know a quite a few areas, but I'm still occasionally stumped for where to run... sorry.

As a side benefit, if there was a timer next to each saying how long its been since it was killed, that'd be cool to.  Not really necessary, of course, but might be a cool add on.
