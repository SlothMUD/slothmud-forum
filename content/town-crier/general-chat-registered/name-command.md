Was talking in channel with a new player last night and highlighted the name command to him, one I find very useful and use all the time. 

I was surprised to find some long time players of sloth didn't know of it.

name \<item\> give the full name of an item that can be used to acurately build equipment change scripts : so rem long-grey-cloak rather than just rem cloak is better as you may be wearing more than one item with the name cloak.

name \<mob\> give a similar full list of the names of a mob that can help both targetting if more than one mb is in a room but also for watchers and ping lists: so tell bearded-drunk ping will accurately identify a single mob while tell drunk ping several different mobs may receive the ping.

Anyone else got any similar useful tips to share?

<div class="post" data-post-id="30608" data-author="*juggleblood*" data-date="2010-01-09T19:31:34+00:00" data-subject="">

Here's a few misc commands newbs might like to learn

\| = clear command queue (lifesaving command)

! = repeat last command

' = say

, = emote

consider = consider killing this mob, how hard is it?

compare = compare 2 similar objects and tell me which is better

examine = will tell you the name of the spell or skill for a book

query (query mobname about objectname)

 used in a shop, this will give you the stats of the object for sale

 used on a forge mob, it might give you the ingredients 

\<direction\> sneak = go that direction while sneaking, leave followers behind

all.food all.scroll

clean = clean the object (clean poison off weapon)

load = load your projectile weapon

typo = attach a new typo to the typos list (room u r in listed automatic)

idea = same, ideas list

bug = same, bugs list

sip = drink a small amount

taste = eat a small amount

pour x y or pour x out= transfer fluids or pour container out
