I would really like to see several modes of looting.  It has always been a big pain in the ass, and I really love the idea of need or greed, and leader only looting.

Modes:

1: free for all - anyone can loot

2: leader control - only the leader can loot for 1 minute, then anyone can loot

3: need or greed - you have 1 minute to to type need, greed or pass.  If someone types need they get it, if multiple people type need then it randoms and the winner gets it.  If no one types need, it moves to the greeds (which is everyone on this mud heh).  And it works the same way, it randoms among them.  If no one types greed and/or everyone has passed on the eq, then the eq stays in the corpse.  Upon winning the roll, the eq automatically goes in the person's inventory.  If no one loots the eq, anyone can loot the eq after 1 minute is up.

I think if these changes are put ingame it could help a lot of eq bitching that goes on.  You're still gonna get people that are going to need when they don't need it, but leaders can remember those few and kick them out of groups.  And just cuz you run need or greed, it doesn't mean that you still can't call eq in groups.
