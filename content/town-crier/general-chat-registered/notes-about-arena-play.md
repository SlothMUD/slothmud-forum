Greetings.

It was reported this week that Level Zero arena was stuck in an occupied state. 

For the time being, it appears as if a simple reboot has remedied this problem.

Feel free to use the arena as normal. 

In the meantime, I want to advise against the following:

1. Using the arena with a shaky connection.

2. Voiding out of the game while in the arena.

3. Dropping link in the arena.

4. Using the quit! command while in the arena.

While not conclusive at this point, it's not unlikely that perhaps a player did one of these

four things while occupying level zero thus not allowing the timeout/reset to take place.

Thanks for your cooperation. If you have any more information regarding this scenario,

please feel free to comment or mail me at neptune@slothmud.org

Thanks.

-Neptune
