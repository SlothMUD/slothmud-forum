Creating a character is done separately from creating an account on the website.  To connect to the game you'll need to find your telnet application and use it.

If you are on windows XP or so, it's best to go: 

Start -> Run

type in telnet slothmud.org 6101

and press enter

In a couple seconds you should be connected to the game.  From there you create your character after a few choices of class orders.  Don't stress on them too much, just pick something that sounds fun and go.  After a few options you'll enter the game and can follow the newbie guide.
