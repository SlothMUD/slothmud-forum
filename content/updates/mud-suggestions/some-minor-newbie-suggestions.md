HI. some newbie suggestions 

1) consolidate isnewbie and newbie mode. 

newbie

Newbie mode is now off.

isnewbie

Is_newbie mode is now off.

I don't really know what the difference is other than isnewbie makes the hints go away - if they're both needed perhaps a rename to clarify the difference.

2) starting spellbooks in guild - suggest make them single time read

I've started several characters to try out the different classes. but then I spend half an hour or more reading spellbooks in the guilds after getting the first couple of levels. In part it takes so long because I start doing other things while waiting for it to complete.

The other spellbooks you can carry I don't mind, you can read them while doing regen, but perhaps the starting spellbooks could all be at least single reads. I ended up just watching a movie and sometimes typing read 2.spellbook. I tried to automate it via script and I'm sure folks have working scripts but the variety of names and messaging meant I just ended up typing it for the most part. I realize once I stick with a character this won't be an issue but coming in and not knowing which class you want to play this takes a lot of play time away up front.
