These went live yesterday as of the last crash.  I believe the issue with the crash has been fixed.  It involved mobs activating zone alarms.

The [target] tag is now off by default and can be toggled using the TARGETTAG command.

The behavior where spells/skills will default to the target if a victim is not specified is now off by default and can be toggled using the TARGETSKILLS command.

The lost concentration message has been changed to include which spell/song failed:

You lost your concentration!  You failed to <cast/play/sing> '<spell name>'.

The failed rescue message has been changed to include the person you failed to rescue.  It looks like I failed to remove the old text, but the new text also shows up:

You fail to rescue <name>.

There were some additional internal changes that hopefully won't show up.
