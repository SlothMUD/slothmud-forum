<div class="post" data-post-id="6343" data-author="kjartan" data-date="2005-05-21T01:52:19+00:00" data-subject="Upcoming alignment changes">

Some more alignment changes will be in next reboot, to refine the last batch a bit:

Necromancers will now have their alignments drop slowly whenever they are maintaining undead followers.

The consider command has been changed to agree with the "challenging" definition.  If a mob considers as "the perfect match" or better, it will count as a challenging kill for alignment purposes.  (note that it's the consider command, not the definition of a challenging kill, that was changed).  (Also note that I am seeing a hard-to-reproduce bug where sometimes things that should count as challenging don't; we're working on this.)

The alignment indicator in the "score" command will correspond with the good/evil levels used for other game effects.

A new spell called 'atonement' will go in which allows you to undo one evil deed per two weeks mud time (about 6 hours real time).  (This will be announced separately in more detail.)
