Upon reboot, new command unsocket will be in-game. 

UNSOCKET

See Also:     SOCKET RUNES GEMS CALL OF THE CUILLEN

Usage:     socket rune objname

Usage:     unsocket rune objname

There are close to a hundred types of gems that can be used to create

runes. This is done through the use of the song "call of the cuillen".

If everything goes right, the sidhe smith will leave you with a rune.

This object can then be socketed into any armor or weapon which does

not already have one. This rune is permanant and can not be removed,

unless the item is one of the following: Triple 40 equipment, Milestone

equipment, or Drachma equipment.

In order to accomplish unsocketing the rune, the player must be inside

a forge and have a small amount of gold.

I have also added some more code to help prevent spammers from disrupting the game. Hopefully this, along with our other anti-spam and censor measures will put help control these idiots a bit...
