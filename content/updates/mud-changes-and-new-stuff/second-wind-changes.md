A few players have brought this skill to our attention and from the looks of things, these changes were a long time coming. Most of you whom have used the skill are fully aware that this has been incredibly overpowering and unbalanced. Originally, this skill was supposed to only work against "external lag" such as bash, web, etc. Obviously this is not what happened. So the changes are below:

SECOND WIND CHANGES

* Upped learn % to 90 from 85

* Lowered moves used from 40 to 30, and for Avatars from 20 to 15

* Removed check for > 0 lag so that skillstats is more accurate 

  ( skill failed if player attempted second wind and player had 0 lag already )

* Added timer so that skill can only be performed once every 3-5 seconds

Enjoy
