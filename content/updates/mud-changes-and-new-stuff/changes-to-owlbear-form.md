**SMALL CHANGES TO OWLBEAR FORM**

```
Before:  1) swipe head target, swipe body target (or w/o target in combat)

Changes: 1) bodyswipe target, headswipe target, swipe target ( or w/o target in combat ).
         2) swipe does random split (head or body) between the two.
         3) it is possible for bodyswipe/headswipe to bash/stun a target.
         4) rather than a generic message for swipe, players now will see the proper melee
            messages so as to have an idea how much damage they actually did.
         5) now uses mana not moves.
```

***** We reserve the right to tweak any and all forms and/or code at any time.
