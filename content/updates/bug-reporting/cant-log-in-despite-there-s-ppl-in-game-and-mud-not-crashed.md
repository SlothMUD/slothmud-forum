Sometimes it can be "name resolution" that's the problem.  You use "slothmud.org" to connect, but your computer translates this to an IP address.  To see if the name resolution is a problem, you can try to connect directly to the IP address.

In windows, you can type this in the command prompt, or just the "run..." box:

telnet 209.139.208.64 6101
