A new trivia system was added with the intentions of having sloth trivia contests. You should see the block for the new system on the right side just under the voting both on the home page. 

Rules for trivia contests when there are prizes: 

You can not win more then twice in a row, and then must sit out for 3 times. 

All trivia worth drachma will be rewarded 1 point per question. So if there is 10 total questions, 10 drachma will be available. 

If there are more then one persons with the same score, the total prize will be split between each person. Ie. Sarge and Blackmore have top place in a 15 question trivia contest, the total drachma available would be 15 drachma. Each person, Sarge and Blackmore would receive 8 drachma. We will round it up to an even number to make the split as fair for all winners as possible. 

We reserve the right to add new rules as we see fit.
